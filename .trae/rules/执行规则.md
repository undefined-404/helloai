## 硬红线（未读文档前也不得违反）

- 不新增第二套 Scheduler / Workflow Runtime / Review Runtime / 状态机 / 事实流
- 不从 `doc/archive/` 恢复旧架构或生成 TODO；与当前代码冲突时以代码与基线为准
- Event 记录执行事实，业务状态机是状态权威；Legacy 与 Runtime 共用同一 Event 契约
- Runtime 不依赖 Planner / Scheduler / Reviewer；Environment ≠ 安全沙箱
- 改动前先输出实现计划；验证优先用既有 `scripts/powershell/` 脚本（约 70 个），不默认新增
- 新增 `.ps1` / `.sh` 必须声明 UTF-8 输出编码；已提交 Flyway DDL 不改
- 完成 ≠ PASS：必须区分 PASS / FAIL / NOT RUN / BLOCKED，执行 git diff / status，按实际结果回填文档

生命周期（Step 0~9）、验证脚本分类、完成报告模板、任务 Prompt 模板见 `doc/HelloAI_AI开发协作规约.md`。
