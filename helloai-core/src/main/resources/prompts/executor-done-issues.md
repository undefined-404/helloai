## 判定要求

- 逐条对照 issues 判断：该问题在本轮产出中是否已被实质解决（有对应的修改、交付物或明确说明）。
- 仅当问题确实被解决时才列入 doneIssues；部分解决、仅声称修复但产出中无法验证、以及完全未处理的问题一律不算已解决。
- doneIssues 中每一项必须与上一轮 issues 中的条目逐字一致（复制原文，不要改写、不要概括）。

## 输出协议

严格输出 JSON，不要输出任何其他文字：

{"doneIssues":["已解决的 issue 原文"],"reason":"一句话总结判定依据"}
