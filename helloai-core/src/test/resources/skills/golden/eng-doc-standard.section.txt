## 平台技能规范（任务所需技能命中 eng-* 规范）
> 以下规范由平台按任务 required_skills 命中注入；产出必须按此执行，审查侧按同一清单核验。

### eng-doc-standard
> 来源：提炼自 DeepSeek Harness `dsh-prose-standard` / `dsh-doc-standards`，已按 HelloAI 语义适配（2026-08-20，§6.114）。
> 定位：约束执行侧交付的文档类产出（说明 / 报告 / 手册 / 注释文档），审查侧 `prompts/subtask-review.md` 轨道 B 文档类 D1-D3 按同一清单核验。

## 执行速览（任务 required_skills 命中 eng-doc-standard 时注入执行 Prompt）

1. **命题完整保留（D1）**：每条「必须 / 不得」的陈述必须含 主体 + 条件 + 模态 + 失败模式——谁、在什么条件下、必须/不得做什么、做不到会怎样。契约性事实（表格 / 代码 / 参数 / 阈值 / 路径 / 状态码）必须原样保留，不得因行文精简而丢失。
2. **tutorial / reference 分离（D3）**：操作步骤（how-to）与概念参考（reference）分节组织，不混写——教程按用户旅程组织，参考按主题词条组织。
3. **无思维链泄漏（D2）**：文档不得出现实现过程叙事（「我们先试了 X 不行改 Y」）、版本戳、设计会话引用、评审编排残留等 8 类泄漏（速查见详细规范）。
4. **信息密度**：删「文档废话」——无信息量的铺垫、重复句、免责声明堆砌；同一结论不重复出现。
