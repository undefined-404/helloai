## 4. 横向对照与结论

| 维度 | deepseek-harness | OpenSandbox | octop-harness |
| --- | --- | --- | --- |
| 工作区生命周期 | 会话级持久（真实目录） | 沙箱实例按 ID 长期存活 | Agent 级持久 |
| turn 结束动作 | 无（持久 shell 也不杀） | 无（显式 pause/destroy） | 无 |
| 文件进上下文 | 文件工具直读路径 | 上传/挂载 + 工具 | 文件工具直读路径 |
| 命令证据 | JSONL + git diff + exit code 标记 | status API / SSE | checkpoint 副产品 |
| LLM 位置 | 宿主循环，调 shell 工具 | 沙箱内 CLI 或外部调工具 | 宿主循环，后端可换 |
| 验证闸门 | 无 | 无 | 无 |

**共同点**：**没有一家在「执行轮」结束时销毁工作区**；工作区寿命都与「会话/任务/Agent」对齐，销毁是显式或终态动作。文件可见性靠「共享同一真实工作区」而不是「模型手抄 ID 再回读」。
