### ② 本计划做什么

**一句话目标**：给「外部 Agent 提交成功」加一道**只登记、不拦截**的交付物存在性闸——`DONE` 状态照常迁移，但「这次完成有没有产物证据」被如实记录下来，为第二段（可见）与第三段（拒收）提供观察数据。

四条具体产出（逐条对应 §3 任务表）：

1. 交付物判据组件：**三取一**（`parts` 非空 / 存在有效 `Attachment` / `output` 长度超阈值）＋ 豁免判定（显式 `noDeliverable` 或 `acceptanceKindDeclared` 为方案/分析类）；
2. `ExecutionResultHandler.handleReport` 接线：**仅 `source=EXTERNAL && success=true`** 时评估，不通过 → `log.warn` + 时间线事件 `delivery_gate_miss`，**不阻断、不改状态**；
3. 时间线事件码新增 `DELIVERY_GATE_MISS`，写点统一 `TimelineEventCode.<CONST>.code()`（过 `verify-event-key-parity.sh`）；
4. 观察期手段：`output` 长度分布统计查询 + 误报率核对口径（判据阈值**不拍脑袋**，先打分布再定）。

### ③ 本计划不做什么

| 不做 | 为什么 | 依据 |
|---|---|---|
| **不做第二段（`gateFindings` 可见）** | 蓝图明确「第二段（观察期后）」——先拿真实误报率分布，才谈得上把结论摆到详情页；现在写 `gateFindings` 等于给一个还没有数据支撑的闸门做展示 | 蓝图 §4 `MA-4` ⑤ 三段递进 |
| **不做第三段（拒收 `accepted=false, reason=no_deliverable`）** | 判据「约束强弱看 fail-open / fail-close」——在能定义「什么算产物」之前 fail-close 必误伤（纯分析类 / 只改配置 / 只回一句话的任务都没有文件产物）；`delivery.enforce` 开关默认 OFF 是第三段的事 | 蓝图 §4 `MA-4` ⑥；判据 9 |
| **不判内部链** | `handleReport` 是内外共用写点，内部链产物由 `ExecutionArtifactService` 物化、本来可靠；统一判据必然有一侧误判。任何「顺手把内部链也管上」的想法都要拒绝——会让验证无法隔离 | 蓝图 §4 `MA-4` ③/⑦ 硬约束 1 |
| **不测 `objectKey` 指向的桶内对象是否存在** | 第一段只查 `Attachment` 行存在（`deleted=0 AND status='ACTIVE'`）；对象存储可达性探测会让闸门依赖 MinIO 可用性，是另一个问题 | 蓝图 §4 `MA-4` ⑦ |
| **不为豁免新开枚举值** | `AcceptanceKind` 已有 `REVIEWED`（方案/设计/分析）与 `ATTESTED`（决策/创意）承载「无文件产物」语义，不新增「分析类」值 | 代码事实 + 蓝图口径订正（见 §4-1） |
| **不改 `submitResult` 入口** | 闸门落点按蓝图钉死在 `handleReport`（提交后置位），不碰 `McpToolServiceImpl` 的既有入口校验 | 蓝图 §4 `MA-4` ⑤；`MA-6` 段落「闸在提交侧」 |

### ④ 诚实边界

**落地后仍有以下不成立，必须同步登记差距表**：

1. **闸门不拦任何东西**。第一段只产生 `log.warn` + 一条时间线事件，`DONE` 照常迁移。「假完成」仍然会成功——只是**开始被记录**。
2. **误报率是未知数**。三取一判据的阈值（尤其 `output` 长度下限）当前无数据支撑，本计划只设**保守默认值 + 可配置**，真实分布要靠观察期采出。在观察期结论出来前，本项**不构成「已完成」**（对照蓝图停止条件）。
3. **豁免通道依赖模型诚实**。显式 `noDeliverable: true` 是模型/用户自报，声明式天然可造假；本期接受（与 `parts` 声明式同源），第三段如需更强证据再议。
4. **时间线事件对前端**：新增事件码后 `verify-event-key-parity.sh` 断言③（`task_timeline.event_type ⊆ 枚举`）保持通过；前端**不必**为它新增 EVENT_META 字典（无该事件时列表不渲染即可），但要确认前端对该未知事件码不白屏（见 §6 验收 7）。

## 4. 关键设计决策

| 决策 | 选了什么 | 为什么不选另一种 |
|---|---|---|
| 判据形态 | **三取一**（满足任一即「有产物」）：`parts` 非空（声明式）/ 活跃 `Attachment` 存在（事实式）/ `output` 长度 > 阈值（兜底） | 只查附件把「纯文本交付」全判成假完成；只查 `parts` 漏掉「老协议 Agent 不上传分片」；只查 `output` 长度会被「复述一遍提示词」骗过。三取一是当前信息量下的最大覆盖 |
| 闸的位置 | **`handleReport`（提交后置位）**，不碰 `submitResult` 入口 | 蓝图明示落点；入口处判会连验证链路一起拦。且 `MA-6` 段落已确认「`MA-4` 坚持闸在提交侧，不与状态机耦合」 |
| 只判 EXTERNAL | 内部链零改动 | 内部链产物由 `ExecutionArtifactService` 物化（可靠）；外部链是黑盒（风险点）。统一判据必然有一侧误判 |
| 第一段形态 | **只 `log.warn` + 时间线事件**，不写 `gateFindings` | `gateFindings` 是「观察期后」的第二段；现在写等于给没有数据支撑的结论做展示 |
| 阈值 | **保守默认 + 可配置**，观察期打分布再定 | 不拍脑袋（蓝图⑦「阈值怎么定」）；又不能让判据因缺配置而不可跑 |
| 豁免形态 | 显式 `noDeliverable: true` **或** `acceptanceKindDeclared` ∈ {`REVIEWED`,`ATTESTED`} | 两类都有「结论即交付物」语义；只认 `noDeliverable` 会让老协议 Agent 无路可走，只认 `acceptanceKind` 会漏掉未显式声明者 |

### 4.1 蓝图口径订正（两处）

| # | 蓝图原文 | 实际事实 | 本计划裁决 |
|---|---|---|---|
| 1 | 「`context.acceptanceKind` 已声明为**分析类**」 | `AcceptanceKind` 枚举**无 `ANALYSIS` 值**；「方案/设计/分析」由 `REVIEWED` 承载（机器判） | 豁免集合 = `{REVIEWED, ATTESTED}`，并在差距表登记口径 |
| 2 | （未写，但验收 4 有歧义）「**内部链跑一个正常子任务 → 行为与改造前完全一致**」 | 内部链也走 `handleReport`（同写点） | 接线分支**必须**先判 `source`，内部链在判据之前短路——实现时用单测锁死 |

### 4.2 已识别的最高危漏项（实现时逐条对照）

| # | 问题 | 本计划如何覆盖 |
|---|---|---|
| 1 | 判据写在 `handleReport` 内联、不可单测 | `MA4-1` 抽成独立纯函数组件，`MA4-4` 只做接线 |
| 2 | 内部链被误伤 | `MA4-6` 单测：同一份 report，`source=INTERNAL` 分支不触发 |

| 5 | 观察期没人看，闸门变成永久开着的告警 | `MA4-7` 给出可一键执行的统计手段 + §6 约定结论周期（对照蓝图停止条件「有人按约定周期看过」） |

## 5. 依赖与实施次序

```text
MA4-1（判据组件，无依赖，先做）
  ├─→ MA4-2（窄查询，判据②依赖）→ 并入 MA4-1 的评估链路
  └─→ MA4-5（豁免键）──────────────→ 并入 MA4-1 的豁免判定
      ↓
MA4-3（事件码，独立可先做）→ MA4-4（接线，依赖 1/2/3/5）
                              └─→ MA4-6（单测，依赖 4）
MA4-7（观察期手段，可与代码并行）→ MA4-8（文档回填，全部完成后）
```

- **`MA4-1` 必须最先**：判据是所有后续的依赖；先写判定再写写点，避免把判据焊死在 handler 里。
- **`MA4-3` 可提前**：事件码是纯增量常量，无依赖，随时可插。
- **`MA4-7` 不需等代码**：统计 SQL 基于事件码聚合，事件码定了就能写。
- **`MA4-8` 收尾**：文档回填照旧每次必做。

### 5.1 停止条件（本计划在哪停是安全的）

| 停在哪 | 安全吗 | 判定口径 |
|---|---|---|
| `MA4-4` 完成（判据 + 接线都通了） | **安全，是干净停点** | `DONE` 照常、warn + 事件开始产生，内部链零改动；不构成「只写不读」（事件被 `verify-event-key-parity.sh` 消费、日志可查） |
| `MA4-7` 未做 | **勉强安全但缺观察依据** | 不满足蓝图停止条件「观察期内有人按约定周期看过误报率」——本项**不得标「已完成」**，只能标「第一段落地，观察期中」 |
| 第三段（拒收） | **不做** | 属后续批次，误报率可接受后才谈 |
