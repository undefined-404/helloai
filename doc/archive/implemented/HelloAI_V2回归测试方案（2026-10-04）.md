### 3.6 RM5 专项：读快照等价性（本轮最大面改动）
> 视图切换涉及 `AgentProfileSnapshot` / `LlmProviderProfile` / `TeamMemberView` / `SubTaskView` / `TaskView` / `AttachmentView` / `UncertaintyView`。**必须验「报文与排序不变」**。

- **REST 报文逐字节**：`GET /tasks/findPlanByTaskId/{id}`、`POST /tasks/confirmPlanByTaskId/{id}`、`POST /requirement-conversations/finalizeById/{id}` —— 与改动前响应 JSON **逐字段比对**（前端类型见 `helloai-ui/src/types/entities.ts`）。
- **排序语义**：草案按依赖拓扑正序（`SubTaskDependencyOrder`）；`listDraftsInInsertOrder` 必须 **createTime asc + id asc**（与 `saveBatch` 插入序一致，否则 dependsOn 回写错位）。
- **空值语义**：`SubTaskReviewServiceImpl`「提交者快照缺失 ⇒ 不跳过」（原 `hasLocalExecutionCapability(null)==true`）——已有双态用例，L2 再兜一次。
- **写命令等价**：`updateContext(Long, Map)` 与旧 `getById→setContext→updateById` 语义一致（取最新行、不存在静默返回）。

### 3.7 B5 专项：成本档位语义（10-04 订正后）
- 单测：`AgentSelectorTest`（55 例）已含 **原 0 档缺陷回归防线**。
- 真实库：已实证 `selectRecentAvgTokenUsage` 口径（近 5 次 / limit / NULL / 排除非 SUCCESS）。
- **仍缺**：**选人层真机**——需 ≥2 个 Agent 各 ≥1 次成功执行产生画像后，观测「更省者胜」。当前覆盖仅 1/12。

## 6. 执行顺序建议（一次完整回归）

1. **L0/L0.5/L1**：`bash scripts/ci/ci-gate.sh --quick --skip-ui` → 快速自检（<2 min）。
2. **重编译 + 重启后端**（本机 `local` profile，端口 6565）——**这是所有 L3/L4 的前提**。
3. **L2**：`bash scripts/ci/ci-gate.sh`（或 `scripts/run-it-local.ps1`）→ 6 个 IT 全绿。
4. **L3**：按 §3.2 顺序（连通性 → 澄清 → 拆解 → 内循环 → token → 报告 → Resume）。
5. **L4**：按 §4.2 顺序（接入 → MCP → 鉴权 → 全链路 E2E → 死信）。
6. **L5**：前端 `npm run type-check && npm run build`。
7. 记录：每项 **PASS / FAIL / NOT RUN / BLOCKED** 四态如实登记（规约 §27：不可用环境不制造假失败）。
