## 准入规则

1. 只收**已经执行完毕**的方案与清单。**未执行 / 进行中 / 待拍板**者一律留 `doc/plan/`。
2. 归档时在 H1 之后补一行头：`> **状态：Done** — …（完成依据 + 归档日期）`。
3. 从 `doc/plan/` 迁入者，须同批从 `doc/README.md` §2.3 表格移除。

## 纪律

- **只读冻结**：不再更新正文。方案若需变更，另立新文档，不改史。
- 文内的版本号 / HEAD 指纹 / 进度数字均为**归档时点快照**，不随仓库演进更新。
- 目录内指向旧路径的引用**有意保留**，见 `doc/README.md` §2.1「引用完整性规则」。
