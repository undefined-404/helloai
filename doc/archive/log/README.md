## 归档规则

1. 每月结束后，以 `git mv` 将 `doc/log/YYYY-MM.md` 移入本目录。
2. **不修改正文内容**。文件头「记录格式与治理规则见 …」的引用**有意保留旧路径**（历史现场），见 `doc/README.md` §2.1「引用完整性规则」。
3. 编号不回收：归档后 `LOG-YYYYMMDD-NNN` 继续全局唯一，新月度不可复用旧编号。
4. 归档动作本身记入当月 Log 的「影响」段。
