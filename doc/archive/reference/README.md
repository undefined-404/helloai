> 本目录是**参考资料区**，不是 Roadmap。存放**未被取代、仍有技术参考价值**的分析与思路文档 —— 与 `legacy/`（已被取代）的关键区别在此。

## 存放什么

| 类别 | 文件 |
|---|---|
| 架构思路 / 口径 | `HelloAI_架构改造长期思路.md`、`HelloAI_架构设计参考.md`、`HelloAI_收敛重构口径校准.md` |
| 技术分析 | `HelloAI_流式输出改造分析.md`、`HelloAI_调度解耦重构分析.md`、`分布式健壮性改造实施清单.md`、`HelloAI_执行产出物化与结构化多文件产出方案.md` |
| 借鉴与设计 | `HelloAI_外部项目借鉴技术细节.md`、`HelloAi Agent 任务调度优先级机制设计文档.md` |
| 历史进度 | `项目进度_历史版.md` |

## 准入规则

1. 只收**有参考价值、但已不构成当前行动依据**的文档。
2. 分派去向须知：
   - **活跃**的对外调研 / 借鉴分析 → `doc/research/`
   - **已成文的稳定设计** → `doc/design/`
   - **进行中的计划 / 方案** → `doc/plan/`
   - **对既成事实的检查 / 审计结论** → `doc/review/`
3. 若某文档的结论已进入实施，其可执行部分须另立 `design/` 文档或差距表条目，本目录只留背景与推导。

## 纪律

- **只读冻结**。引用本目录内容作论据时，必须标注其为**历史参考**并复核当前代码。
